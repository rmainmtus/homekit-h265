# Security reports

Do not publish credentials, pairing state, private recordings or exploit details
in a public issue. If GitHub's **Security → Report a vulnerability** is available
for this repository, use that private reporting channel. Otherwise open an issue
requesting a private contact method without including sensitive details.

This is experimental community software. Use it on a trusted LAN, keep Home
Assistant and camera firmware updated, and do not forward its ports to the
internet. App backups contain secrets. Logs intentionally suppress raw media
process errors because RTSP URLs may contain credentials.
